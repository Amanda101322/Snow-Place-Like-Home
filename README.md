# Snow-Place-Like-Home
link: https://snow-place-like-home.vercel.app/
Shake for a little winter kindness! This is a cozy, interactive web app built to spread warmth, gentle fortunes, and peaceful snowy vibes. Twas made with lots and lots of love.
## Features: 
* **Friendly Snowman Welcome:** When you open the site in a browser, a greeting snowman animaation appears. It uses HTML and JavaScript to check the time of the day and give you a fitting welcome so you feel at home immediately.
* **Shakeable Snowglobe:** The highlight of the site... Give the globe a shake and it will bring up a new piece of winter advice or encouragement.
* **Animated Fortune Cards:** When the globe is done shaking, a little card pops and slides into view with a winter message.
* **Live Canvas Snowfall:** The beauty of the site....there's background snow drops falling while you use the site and it's rendered in real time using HTML5 canvas JavaScript.
* **A Warmth Meter** which keeps track of how many times  the snowglobe has been shaken. The count is saved in your browser using local storage, so it stays there even when you come back later. The number goes up in +1 as you continue shaking.
* **Light/dark mode toggle:** You can switch between a soft daytime sky and a oh so dreamy starry midnight theme whenever you click the toggle.
* **Cozy Chimes:** A little bell sound plays when the globe is shaken to make it feel more like you're actually shaking the globe. There's also a sound-off button if you want a quiet browsing session.
